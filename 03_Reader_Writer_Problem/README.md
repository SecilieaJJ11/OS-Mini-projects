# Reader-Writer Problem

## Use Case

### Product Inventory Management

This project demonstrates the Reader-Writer problem in a product
inventory system where multiple users can view and update inventory
details at the same time.

## Concept

* Multiple readers can access the inventory data at the same time.
* A writer gets exclusive access while updating the shared data.
* Synchronization helps maintain consistent and correct data.

## Concepts Used

* Threads
* Reader-Writer Synchronization
* Read-Write Locks
* Mutual Exclusion
* Critical Section
* Shared Resources
* Process Synchronization
* Concurrent Access
